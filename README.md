# Delivery_Bot
To develop an autonomous delivery robot capable of transporting items between designated location in an indoor environmentusing ROS2. Robot will perform autonomous navigation, mapping, localization, path planning, and obstacle avoidance to complete delivery task efficiently.


| Task | Description | Date |
|------|-------------|------|
| TASK 1 | Defining project objective, robot dimensions, LiDAR placement, and creating the architecture | 16-Jun |
| TASK 2 | Designing in Fusion 360 and creating the URDF file | 19-Jun |
| TASK 3 | Configure Gazebo simulation environment | 21-Jun |
| TASK 4 | MoveIt configuration | 22-Jun |
| TASK 5 | Integrate LiDAR sensor and verify scan data | 23-Jun |
| TASK 6 | Implement SLAM Toolbox and generate the map | 24-Jun |
| TASK 7 | Configure AMCL localization using saved map | 24-Jun |
| TASK 8 | Configure Nav2 navigation stack | 25-Jun |
| TASK 9 | Create delivery workflow | 26-Jun |
| TASK 10 | Testing and debugging | 26-Jun |

## PROJECT OBJECTIVES
The objectives of this project are

- Learn ROS2 Robot Development
- Design a mobile robot from scratch
- Create a URDF model
- Simulate the robot in Gazebo
- Integrate LiDAR
- Perform SLAM Mapping
- Implement AMCL Localization
- Configure Navigation2
- Perform autonomous indoor delivery
